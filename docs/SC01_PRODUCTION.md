# SC01 — обновление по Production Pack

Сцена встроена в прежний кинематографичный проигрыватель. Точка входа: http://localhost:5173/?story=neoreul_mideo. Для просмотра с начала: меню «···» → «Начать заново». Старый прогресс продолжает восстанавливаться.

## Содержание

- Восемь **отдельно сгенерированных** изображений SH01–SH08. Кадры раскадровки не используются в обновлённой SC01. Юна, Минсу, комната, одежда, тёплый свет и альбом удержаны общими визуальными референсами.
- 19 общих шагов, включая выбор D16, и три возможные реакции. За одно прохождение: 20 шагов, ровно восемь изображений в порядке SH01→SH08.
- SH04 остаётся на D05–D10; SH05 — D11–D14; SH07 — на выборе, любой реакции Минсу и D17. Минсу на SH07 говорит за кадром. Следующий новый кадр — SH08.
- Все `original`, `simple`, переводы, реакции и примеры ответов взяты буквально из пакета. Последний переход `SC02_START` адаптирован к существующему `SC02_01`.
- Действия выбора SC01 показаны **по-русски**, согласно новому production pack; готовые корейские ответы доступны только преподавателю. Во второй сцене сохранён прежний формат выбора.

## «Проще»

Кнопка изменяет только текущую корейскую строку. «Оригинал» возвращает основной текст. На следующем шаге, реакции, возврате и переходе через пульт преподавателя показывается original. Если формулировки совпадают (D03), кнопка скрыта. Состояние упрощения не входит в сохранения, не применяет эффекты, не меняет кадр, выбранную ветку или историю посещений.

Режим преподавателя показывает обе версии, русский смысл, грамматику, лексику и комментарии; на выборе — оригинальный и простой образец ответа.

## Файлы

- `public/stories/neoreul_mideo/assets/scene_01/SC01_SH01.webp` … `SC01_SH08.webp` — игровые изображения.
- `nodes.json`, `scenes.json`, `story.json` — новые узлы/кадры, выборы, миграция старых ID.
- `src/main.tsx`, `src/cinematic.css` — кнопка и учительские материалы в прежнем UI.
- `src/engine.ts` — чтение версии текста и перенос старых сохранений; граф и механизм возврата прежние.
- `src/types.ts`, `src/validate.ts`, `story.schema.json` — новые необязательные поля.
- `src/production.test.ts` — точность текста, последовательность кадров, миграция, календарь.
- `docs/sc01-production/` — исходный пакет и полный набор запросов генерации.

Старые сохранения SC01 сопоставляются с ближайшим по смыслу новым ID. Сохранения внутри SC02 остаются на том же экране; `first_question` и `route` сохраняются. Добавленные флаги фактов восстанавливаются по истории сделанных выборов. Полный новый ритм первой сцены лучше оценивать с начала.

## Явные согласования и ограничения

1. Генератор выдал **1672×941** для всех восьми кадров, ниже ориентира 1920×1080. Изображения не увеличивались программно. Игровые WebP имеют те же размеры, PNG-оригиналы переданы отдельно. Это новые самостоятельные иллюстрации, но требование к разрешению остаётся ограничением текущей версии.
2. Календарь: в SC02_14 и SC02_16 событие в квартире теперь отнесено к **четвергу**. «Вчера» в SC02_13 оставлено: оно относится к пятничному разговору Минсу и Юны, а не к визиту в квартиру. Другие реплики SC02 не переписывались.
3. В пакете есть расхождение учебного комментария D04: карточка Markdown указывает `-지 않고`, JSON — `-고 있지 않다`. Сама корейская реплика в обоих источниках одинакова. В учительском блоке оставлена JSON-аннотация, соответствующая фактической форме реплики; альтернативное указание зафиксировано здесь, сюжет и реплика не изменены.
4. В первой версии пакета упоминается `SC02_START`, такого ID в движке не было. Это технический псевдоним существующего `SC02_01`, а не новая сюжетная сцена.

## Проверка

`npm test`, `npm run validate`, `npm run build`. Браузерная проверка проходит все пары original/simple, три ветки, возврат и смену ответа, переход SC02, refresh, teacher mode и компоновку 1440×900, 1280×720, 390×844. Скриншоты и архив проекта приложены к результату.
