## Переход после D16

- **Прямо из SC02** → символический `SC04A_START` (первая конфронтация: Юна не видела полку).
- **После SC03A** → символический `SC04B_START` (другая конфронтация: Юна уже поверила объяснению о полке).

Не смешивать с концовкой B: она будет выбором **после признания Минсу**.
