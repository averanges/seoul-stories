# Seoul Stories — Ending B Production Pack

Финал **B «Не одна»**: Юна порвала отношения с Минсу и принимает поддержку Соры, не зная, что именно Сора была второй женщиной. Сцена в старой квартире из SC01, вечером в воскресенье.

- `01_SCRIPT_CARDS.md` — короткий русский сценарий и структура.
- `02_FULL_SHOT_CARDS.md` — режиссура **трёх** новых уникальных иллюстраций.
- `03_DIALOGUE_READING.md` — полный корейский Original/Simple, RU и подсказки преподавателю.
- `04_VISUAL_BIBLE.md` — референсы, карта комнаты, набор ракурсов, реквизит и запреты.
- `05_CODEX_TASK.md` — интеграция, переходы, проверка.
- `data/ENDING_B_content.json` — переносимая структура, не гарантированно совпадающая с проектной schema.
- `references/` — кадры из готовой игры (референсы, **не** финальные картинки).
- `assets/ending_b/` — отметка, что три игровые иллюстрации ещё предстоит сгенерировать.

**Не путать:** `ENDING_B_NOT_ALONE` — новый финал B; `SC04A_CONFESSION` — личное признание, `SC04B_PHONE` — ночной звонок; готовый счастливый финал A изменять не требуется.
