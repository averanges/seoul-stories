# SC06 — Лучшая подруга

Новая сцена SC06_SORA_CONFRONT включена в общую сборку neoreul_mideo. Реальные узлы SC06_D01–SC06_D34, семь изображений SC06_SH01–SC06_SH07, выборов внутри нет. Source of truth: docs/sc06-production/data/SC06_content.json; все корейские варианты, перевод, порядок, пунктуация и заметки сохранены.

## Подключение

Оба прежних выхода раскрытия имени теперь ведут к одному SC06_D01: SC04A_REVEAL_OUT_A и SC04B_REVEAL_OUT_B через сохранённые совместимые ID SC06_SORA_CONFRONT_START / SC06_SORA_CONFRONT_PHONE_PENDING. На обычном маршруте прокладки условно пропускаются без пустого экрана и лишнего нажатия. Вход SC06_D01 требует sora_identity_known=true; при отсутствии флага возвращает к SC02_D26.

Старые сохранения двух прежних continuation-заглушек мигрируют в SC06_D01, не меняя переменные и историю. Это продолжения, не завершённые финалы: сохранения ENDING_A_FALSE_PEACE / ENDING_B_COMPLETE не перенаправляются. LEAVE по-прежнему ведёт в Ending B. Оба KNOW → раскрытие имени → SC06; раскрытие остаётся на R04 прежних сцен, не перенесено в кафе.

После D34 существует реальная guarded-заглушка ENDING_C_START на последнем кадре: «Продолжение следует» / «Финал C ещё не добавлен». Финал C не создан и не подменён другим финалом. Валидатор не обнаружил битых или недостижимых целей.

## Учебный режим и механика

Teacher.translation и note сохранены дословно. vocabulary разделён по точке с запятой, пункты с грамматикой дополнительно отображаются в teacher.grammar. «—» означает пустой словарь. Original/Simple переключается только для текущей реплики, прежний сброс при next/back/teacher jump сохранён, на одинаковых текстах кнопка скрыта. Никаких новых таймеров, автоматического чтения или выбора. Все флаги сохраняются неизменными на34шагах; новых сюжетных фактов код не додумывает.

Данные адаптированы к существующей схеме scene/src/teacher/when/skipTo. Код плеера/движка, стили, прошлые узлы (кроме двух continuation-подключений), прежние картинки и финалы сохранены; проверки SHA-256 это подтверждают.
