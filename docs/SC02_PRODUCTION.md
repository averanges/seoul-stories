# SC02 «Покупки с Сорой» — интеграция Production Pack

Демо: http://localhost:5173/?story=neoreul_mideo

SC02 начинается после последней реплики SC01. Для быстрой проверки: включите режим преподавателя, в списке экранов выберите `SC02_D01` и нажмите «Перейти». Переход через пульт сохраняет текущие переменные. Для полного нового прохождения — «···» → «Начать заново».

## Контент и изображения

Интегрированы точные 26 общих шагов и две реакции из `SC02_content.json`. На одном маршруте — 27 шагов, восемь иллюстраций SH01→SH08 без возвращения к предыдущим кадрам. SH02 удерживается на шести репликах о диване, SH06 — на семи репликах рассказа Юны. Смена говорящего не меняет кадр.

Созданы **восемь отдельных изображений встроенным image_gen**:

| Файл в `public/stories/neoreul_mideo/assets/scene_02/` | Содержание |
|---|---|
| `SC02_SH01.webp` | Юна и Сора входят в светлый магазин |
| `SC02_SH02.webp` | Сора примеряет большой трёхместный диван |
| `SC02_SH03.webp` | Юна держит две кружки: кремовую и голубую |
| `SC02_SH04.webp` | Сора физически добавляет розовую кружку к двум в корзине |
| `SC02_SH05.webp` | У парных светильников Юна задумывается; в корзине три кружки |
| `SC02_SH06.webp` | Юна тихо рассказывает Соре о разговоре с Минсу |
| `SC02_SH07.webp` | Сора даёт доброжелательный совет; три кружки остаются в корзине |
| `SC02_SH08.webp` | Выход из магазина, бумажный пакет с тремя кружками, решение Юны |

Раскадровка использовалась только как режиссёрский референс. Финальная внешность Юны из SC01 — приоритетный референс лица. Во второй сцене у неё кремовый открытый кардиган, светлая футболка, частично собранные волосы и сумка; у Соры — серое худи, тёмное каре и сумка через плечо. Все кадры дневные; Сора не показана подозрительной.

**Ограничение разрешения:** генератор вернул 1672×941 для каждого кадра. Изображения не увеличивались программно. WebP quality95 имеют исходные размеры; оригинальные PNG переданы отдельным архивом. Запросы и размер каждого изображения сохранены в `docs/sc02-production/GENERATION_PROMPTS.md` и `ART_MANIFEST.json`.

## Ветки и сохранения

Варианты выбора на D26 показаны по-русски. Корейские образцы original/simple доступны преподавателю. `direct` → `SC02_R_TALK`, `route="talk"`; `check` → `SC02_R_CHECK`, `route="investigate"`. Внутренние ID вариантов `direct`/`check` сохранены от прошлой версии для совместимости; это те же действия `talk`/`investigate` из пакета.

Обе реакции остаются на SH08 и используют прежние метаданные «Продолжение следует» с обозначением будущей ветки. SC03 не создана; переходов к отсутствующим `SC03A_START`/`SC03B_START` нет. Реакция не повторяется отдельным дублирующим экраном.

Карта миграции из пакета добавлена к существующей `saveMigration.nodes`. Старые `SC02_01`…`SC02_20`, `SC02_C1` переводятся на соответствующие новые шаги. Старые `SC02_END_A`/`SC02_END_B` переводятся на новые терминальные реакции `SC02_R_TALK`/`SC02_R_CHECK`; сами новые ID больше не переназначаются. Поэтому повторное сохранение/перезагрузка не создаёт цикл. История, `first_question` и `route` сохраняются; возврат из реакции отменяет только последний выбор.

Даты сохранены буквально из пакета: визит и шум — четверг, звонок — пятница, покупки — суббота. `어제` в D18 обозначает пятничный звонок, а не визит Минсу.

## Что изменено

- Только SC02 в `nodes.json` и `scenes.json`, восемь новых игровых WebP.
- В SC01_D19 изменена **только соединительная ссылка** с удалённого `SC02_01` на новый `SC02_D01`. Тексты, original/simple, выборы, кадры и восемь иллюстраций SC01 сохранены.
- В `story.json` дополнена карта переноса старых ID; начальные переменные и правила SC01 не изменены.
- Добавлены тесты SC02, обновлены ожидаемые ID в прежних проверках.
- Общие `main.tsx`, `cinematic.css`, `SceneImage.tsx`, `engine.ts` и `storage.ts` не изменялись. Их SHA-256 и исходный контент SC01 зафиксированы в `SC01_BASELINE.json` и проверяются тестом.

## Проверки

`npm test` — 20 проверок: точность bilingual-контента, исходная SC01, 27 шагов и восемь кадров каждой ветки, все старые ID, перенос выбранных маршрутов, возврат, перезапуск, общие маршруты обеих сцен. `npm run validate` и production-сборка также проходят.

В браузере проверяются все 28 original/simple пар, отсутствие изменений изображения и сохранения при упрощении, возврат к original на следующем шаге, удержание SH06, обе ветки, refresh, миграция старого сохранения, пульт преподавателя, fullscreen и размеры 1440×900, 1280×720, 390×844. Скролл документа на игровых экранах не требуется; материалы преподавателя имеют собственную прокрутку.

Полная финальная оценка графики остаётся за пользователем, как предусмотрено заданием. Содержательных изменений диалогов или новых сюжетных фактов не добавлено.
