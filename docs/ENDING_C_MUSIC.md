# Музыка Ending C — прототип сравнения

Открыть http://localhost:5180/?story=neoreul_mideo. В Ending C у ученика появляется кнопка ♪ (вкл./выкл.). В пульте преподавателя — блок «Музыка финала C»: «Без музыки», «Обычный цикл», «Адаптивный режим», громкость и «Повторить Ending C». По умолчанию адаптивный режим, 35%; настройки сохраняются отдельно от сюжетного прогресса. Звук запускается только после взаимодействия с игрой.

Для быстрого просмотра преподаватель может перейти на `ENDING_C_D01` после прохождения раскрытия имени Соры. Проверки входа в историю сохранены; кнопка повтора сохраняет переменные и добавляет новый вход в историю посещённых экранов.

## Материал и интервалы

Исходник пользователя: «Minimalist tragic instrumental soundtrack for the ending of.wav», 60 секунд, PCM 16 bit, stereo, 44100 Hz. Полный файл без изменений сохранён локально как `public/stories/neoreul_mideo/assets/ending_c/music/full.wav`.

| Фрагмент | Интервал исходника | Использование |
|---|---|---|
| intro.wav | 00:00–00:06 | Один раз при старте/повторе |
| loop.wav | 00:14–00:21 | Повтор до финального сюжетного события |
| outro.wav | 00:33–01:00 | Один раз на D06; заканчивается и на экране конца |

Границы выбраны по анализу громкости и повторяющихся трёхсекундных атак, а не равными третями. У спокойного участка атаки около 15-й и 18-й секунд; 14–15 и 20–21 — тихие хвосты для перекрытия. Наиболее сильное нарастание расположено после 33-й секунды. Вступление заканчивается до более громкой атаки на 9-й секунде.

Фрагменты вырезаны по целым PCM-отсчётам без нормализации и перекодирования. В Web Audio первая петля начинается на 5-й секунде вступления, затем каждые 6 секунд; её семисекундные копии перекрываются на 1 секунду с линейными fade-in/fade-out. Так сохраняется трёхсекундная сетка нот. Переход к outro — crossfade 2 секунды, окончание outro — fade-out 2 секунды. Начало обычного полного цикла — fade-in 1,2 секунды; отключение/выход — fade-out 1,2 секунды. При смене режима новый вариант запускается после затухания старого. Два фрагмента перекрываются только в предусмотренных crossfade.

Границы являются рабочим вариантом для музыкального сравнения. Проверены планирование, уровни и отсутствие жёстких цифровых стыков; субъективная незаметность повторения и гармоническая естественность требуют прослушивания. Плеер позволяет сравнить варианты непосредственно в сцене.

## Реальные сюжетные события

`ENDING_C_D01`–`D05`: intro → спокойная loop; переходы между строками, Original/Simple и открытие преподавателя ничего не перезапускают.

`ENDING_C_D06`: outro. `ENDING_C_TERMINAL`: то же состояние, без повторного запуска; музыка доигрывает и замолкает. Быстрое нажатие «Дальше» не блокируется.

В тексте нового задания есть расхождение с существующей сценой: телефон берут/откладывают на D05/SH02, SH03/D06 содержит последнюю строку «В ту ночь Юна никому не позвонила». Выбран требуемый последний текстовый шаг D06, без изменения сценария и кадров. При возврате из D06 к D05 восстанавливается спокойная петля. При «Повторить Ending C» вновь начинается вступление. При уходе из C, в другую историю или библиотеку текущая музыка затухает, состояние сбрасывается.

Один контроллер управляет источниками и отменяет отложенные старты при быстрых сменах режима. Таймер обслуживает только предварительное планирование петли, не развитие сюжета и не запуск кульминации. Ошибка получения/декодирования WAV выводится в музыкальном блоке и не мешает навигации. Другие сцены не получают музыку.

## Проверки

Автоматическая проверка моделирует пять минут на спокойном шаге, затем быстрый запуск D06/конца, A/B/выключение, отмену отложенных запусков, повтор со вступления и уход в тишину. Браузерная проверка использует реальные WAV и AudioContext: запуск по жесту, отсутствие перезапуска от «Проще», outro на D06, смена режимов, повтор, уход из истории, мобильная компоновка и HTTP 404 без блокировки сюжета. Отдельный трёхминутный прогон проверяет удержание спокойного состояния в реальном AudioContext; результаты — `outputs/ending-c-music-hold.json`.

Все 66 тестов и production-сборка прошли. Проверка сэмплового микса: пик 0,550 (без clipping), изменение соседних отсчётов непосредственно на стыках около 0,00064. Запись повторяющейся петли для прослушивания: `outputs/ending-c-loop-audition.wav`; числовой отчёт: `outputs/ending-c-loop-check.json`. Мобильная кнопка проверена на 390×844, блок преподавателя — на 1280×720.

Диалоги, JSON маршрутов, иллюстрации и движок истории не изменены. Интеграция UI в main.tsx отражена в `ENDING_C_MUSIC_AUDIT.json`; исторические проверки сохранности обновлены только для утверждённого изменения этого файла, прежние контрольные суммы сохранены в аудите.
