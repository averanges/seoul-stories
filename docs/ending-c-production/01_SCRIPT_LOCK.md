# SCRIPT LOCK — Ending C «Никого» / 혼자

**Хронология:** воскресенье, поздняя ночь, ПОСЛЕ SC06 «Лучшая подруга» в кафе. Технический ID: `ENDING_C_ALONE` (проверить реальные ID перед вставкой).

**Замысел:** После потери Минсу и Соры Юна возвращается в старую квартиру и впервые остаётся совсем без поддержки. Это не новая конфронтация; ни слова о том, кто виноват, ни подробного финального монолога.

**Сценарная последовательность (визуальные действия, не реплики для дословного перевода):**

1. **Возвращение.** Юна заходит домой глубокой ночью, закрывает дверь и несколько секунд стоит, не двигаясь. Глаза красные после кафе; она уже не кричит и не плачет навзрыд.
2. **Незавершённая жизнь.** На журнальном столике закрытый фотоальбом, рядом коробки для переезда. Ничего не убрано. Юна берёт телефон, но почти сразу опускает его.
3. **Последний кадр.** Она сидит одна на полу возле дивана. Там, где в Ending B рядом была Сора, теперь пустое место. Последняя строка: «В ту ночь Юна никому не позвонила». После неё задержать изображение и показать «Конец C — Никого».

**Длительность/ритм:** 3 иллюстрации, 6 коротких текстовых шагов; последняя иллюстрация может держаться дольше. Не вставлять новые неожиданные звонки или сообщения. Музыка и движение — только если уже поддерживаются существующим плеером; можно использовать тишину.

**Принципиальная непрерывность:** В Ending B Сора приносила домой пиво. В Ending C встреча Соры и Юны происходила в кафе, поэтому **никаких банок пива или привезённой Сорой еды в этой квартире не должно быть**. Эмоциональное зеркало этих финалов — присутствие/отсутствие подруги, не одинаковый реквизит.
