## Dialogue and metadata

Импортировать ровно шесть текстовых шагов D01–D06 из `data/ENDING_C_content.json` или `03_DIALOGUE_READING.md`, с полями `speaker`, `original`, `simple`, `ru`, `grammar`, `vocabulary`, `teacher_notes`. Все шаги принадлежат рассказчику, персонажи не произносят реплик.
