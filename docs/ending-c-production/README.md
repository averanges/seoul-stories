# Seoul Stories — Ending C «Никого» / 혼자

**Последняя сцена истории** после SC06: Юна возвращается в старую квартиру одна. Три самостоятельных иллюстрации; шесть коротких реплик рассказчика; никакой новой интриги и никаких выборов.

Порядок документов:
- `01_SCRIPT_LOCK.md` — утверждённые смысл и краткая русская версия;
- `02_FULL_SHOT_CARDS.md` — конкретные ракурсы, композиции и генерационные брифы;
- `03_DIALOGUE_READING.md` — полный корейский Original/Simple, RU, грамматика, словарь;
- `04_VISUAL_BIBLE.md` — старый интерьер SC01, зеркальная композиция к Ending B, непрерывность;
- `05_CODEX_TASK.md` — инструкция по интеграции;
- `data/ENDING_C_content.json` — структурированный **контракт**, не обязательно нативная схема движка;
- `references/` — утверждённые игровые референсы Юны и комнаты;
- `assets/ending_c/` — целевые файлы изображений пока отсутствуют: генерация на стороне Codex.

**Не допускать логической ошибки:** банки пива были только в Ending B. Сора и Юна в C виделись в кафе, поэтому дома напитков Соры быть не должно.
