# VISUAL BIBLE — Ending C «Никого»

## Основная установка

Корея, реалистичная повседневная визуальная новелла. Финал C не должен становиться хоррором или глянцевой «плачущей фотосессией». После сцены кафе Юна возвращается домой полностью истощённой. Тёплая лампа и обычные вещи контрастируют с отсутствием людей.

## Локация — только старая квартира из SC01

Референс `SC01_old_apartment_room.jpg` имеет приоритет над словесным планом. Он не лицензирует пересоздание интерьера. Не использовать НОВУЮ квартиру с полкой из SC03A/False Ending A.

Условная карта (ориентир относительного положения):

```text
                [ОКНО / ГОРОД НОЧЬЮ]
[тумба + лампа]   [коробки]    [стеллаж]

        [НИЗКИЙ СТОЛИК]      [ДИВАН]
               [КОВЁР / ПУСТОЕ МЕСТО]
         [ПРОХОД / ДВЕРЬ]
```

- SH01 — входная зона: НЕ пытаться изобразить всю квартиру.
- SH02 — только столик, альбом, телефон, часть коробок. Архитектурные якоря не видны.
- SH03 — вид **от окна** в сторону дивана/ковра/столика; окно за камерой, чтобы не создавать новый план. Это зеркальный ракурс к Ending B SH03.
- Сильная смена ракурса важнее мелких вариаций позы. Комнату не переставлять.

## Факты и реквизит

- Юна одна, никаких Соры и Минсу, даже в отражениях, на экране телефона или в фото.
- После сцены SC06 одежда, причёска и сумка должны совпадать с утверждённой игровой версией. Если SC06 ещё не сгенерирована, Codex должен сначала взять её как источник визуальной непрерывности, а не выдумать новый образ.
- Старый фотоальбом лежит **закрытым**, он является знакомой вещью, не новой уликой.
- Коробки для переезда остались. Не меняем декор и мебель.
- **Пиво и еда из Ending B не появляются**: в ветке C Сора встречалась с Юной в кафе, а не приходила к ней домой.
- Один телефон, без сообщений, без readable интерфейса, лежит экраном вниз к финалу.

## Эмоция и монтаж

Слёзы были в SC06. Здесь Юна измучена; яркая эмоция уступила пустоте. Не обнимать подушку, не ронять вещи, не показывать обморок. Между репликами допустимы паузы, но Codex не должен добавлять таймеры или ломать ручное продвижение текста.

**Визуальная рифма:** Ending B SH03 — две женщины сидят рядом. Ending C SH03 — Юна на том же ковре одна и заметно пустое место рядом. Это должно быть понятно даже без нового предмета-символа.
