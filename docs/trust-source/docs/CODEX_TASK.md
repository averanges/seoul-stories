# Задание Codex: встроить первые две сцены в существующий Seoul Stories

## Цель
Нужен **играбельный вертикальный срез** истории «Ты мне веришь?» внутри уже существующего проекта, а не новый standalone HTML и не новый дизайн. Используй текущий player, library screen, teacher mode, fullscreen, progress, restart, etc. Подстрой данные пакета `story_data.json` под реальную схему проекта. Не меняй архитектуру без необходимости.

## Что сделать
1. Разобраться с текущим форматом истории/нод, роутингом, загрузкой картинок. Не предполагать, что наш JSON уже совпадает с твоим API.
2. Добавить новую историю в библиотеку: «Ты мне веришь?» / `정말 믿어?`; 2 сцены. На старте демо 1A–1B.
3. Все ноды из `story_data.json` отрисовать по порядку: на основном экране короткий **корейский** текст, speaker tag, кнопка «Дальше». Для `narrator` нет имени персонажа.
4. Для нод `type=choice`: показать 2–3 выбора (русская подсказка/задание учителю допустима только при teacher mode; в ученическом режиме варианты можно показывать короткими корейскими фразами на основе `exampleKo`), после выбора **сначала устная реплика ученика**, преподаватель отмечает вариант, затем **заменить выбор на реакцию** (нода `SC01_R*` или route_end), как в нашем прежнем подходе. Никаких текстовых форм или STT.
5. Сохранять `first_question` и `route`, чтобы позднее использовать в SC03, и восстанавливать выбор после refresh. Сохранение должно включать id текущей ноды и историю шагов, чтобы Back не путал ветви.
6. Переход из SC01_16 прямо в SC02_01, со сменой заголовка и тональности (вечерняя квартира → светлый магазин). Не сбрасывать историю.
7. `SC02_END_A` и `SC02_END_B` — завершение доступного демо. Показать «Продолжение следует» + название будущей ветки. Не изображать несуществующий финал и не пытаться отрисовать отсутствующую SC03.
8. В teacher mode показывать русский смысл, пример корейской устной реплики, грамматические примечания. В обычном режиме — только корейский текст и дружественная навигация.
9. Использовать временные картинки из `images/` через обычный asset loader. Относительные пути сохранены в JSON. Нельзя просто ставить целую раскадровку как статический фон на все экраны.
10. В UI графику вписывать без искажения: `object-fit:contain` или аккуратное позиционирование, не растягивать лица. **Текущая графика черновая** — эстетические проблемы разрешения здесь не критерий качества проигрывателя.

## Пройти вручную 4 сценария
- SC01: выбор 1 → SC02: прямой разговор → завершение демо A.
- SC01: выбор 2 → SC02: проверить управляющего → завершение демо B.
- SC01: выбор 3 → Back → изменить выбор → реакция корректно заменена.
- Перезагрузить страницу в SC02, проверить тот же текущий экран и сохранённые флаги.

## Окончательные критерии
- Одна версия игры, а не два разных демо.
- Переход без перезагрузки страницы между сценами.
- 1–2 корейских предложения на экране; длинные тексты из teacher mode не мешают ученику.
- Никакого ручного ввода речи, STT и таймера.
- Смена картинок и эмоций по подготовленному `image` каждого экрана.
- Все временные ассеты помечены, чтобы затем массово заменить их на чистые полноформатные изображения без правок сценария.
- После интеграции сообщить точный путь проекта, запуск, изменённые файлы, как тестировать оба маршрута.
