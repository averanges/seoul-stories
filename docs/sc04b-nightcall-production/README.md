# Seoul Stories — SC04B / Ночной звонок

Пакет для Codex включает два уровня подготовки: сначала **сценарные карточки** (`01_SCRIPT_CARDS.md`), затем **production pack** (`02_FULL_SHOT_CARDS.md`, `03_DIALOGUE_READING.md`, `04_VISUAL_BIBLE.md`, `05_CODEX_TASK.md`, JSON и референсы).

**Не загружайте как готовую SC04B:** игровые иллюстрации ещё нужно создать. Это пакет для генерации/интеграции в текущий проект. Изображения в `references/` служат только референсами.

**Сюжетный вход:** только после SC03A (полка) + SC03B (охранник). Для прямого прихода к охраннику используется SC04A_CONFESSION. Концовка A — отдельный существующий артефакт, не перезаписывать.

**Композиция:** ровно три новых изображения, Юна одна, Минсу только голосом по телефону. Главный момент — D07 «А я ведь сегодня тебе поверила». Вопрос «Кто она?» и ответ «А это важно?» ОБЯЗАТЕЛЬНЫ до выбора.

**Точки перехода** `SC05_IDENTITY_START` и `ENDING_B_START` символические; Codex должен найти их действительные ID или подготовить безопасные заглушки, не изобретать существующие связи.
