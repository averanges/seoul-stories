# «Ты мне веришь?» — интеграция двух сцен

Новая история встроена в прежний Seoul Stories. Библиотека, компоненты проигрывателя и оформление сохранены. Предыдущая история «Последний поезд» остаётся доступной.

## Открыть

Из папки проекта:

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Прямая ссылка: http://localhost:5173/?story=neoreul_mideo

Библиотека: http://localhost:5173/

Параметр `story` открывает историю сразу и восстанавливает последний экран из localStorage. При обновлении страницы во второй сцене открывается тот же экран, а не библиотека. Без сохранения история начинается с `SC01_01`. Кнопка «Библиотека» убирает параметр, сохраняя прогресс.

## Контент

- 43 исходные ноды, все ID сохранены.
- 25 оригинальных JPG из `images/`, без генерации и изменения кадров.
- SC01 «Старые фотографии»: три варианта вопроса → соответствующая реакция Минсу → общее продолжение.
- `SC01_16` → `SC02_01`: прямой переход с вечерней квартиры в светлый магазин, с новым заголовком сцены и сохранением истории шагов.
- SC02 «Покупки с Сорой»: два варианта → `SC02_END_A` или `SC02_END_B`.
- Оба последних экрана показывают «Продолжение следует» и будущую ветку. SC03 не создана; исход ситуации не утверждается.

Ученик видит короткую корейскую реплику, корейское имя персонажа и корейские варианты. У рассказчика нет имени персонажа. Русские переводы, задания, примеры устных ответов и исходные грамматические примечания отображаются только при включённом режиме преподавателя. Русские элементы управления приложения сохранены.

При выборе сразу открывается отдельная нода реакции с её изображением и говорящим; варианты исчезают. «Дальше» продолжает сюжет без повторения реакции. «Назад» из реакции возвращает к выбору и отменяет его флаг. После более позднего экрана возврат сначала открывает предыдущую реакцию, затем позволяет отменить выбор.

## Сохранённые флаги

```text
first_question: null → "what" | "noise" | "none"
route:          null → "talk" | "investigate"
```

Строковые значения сохранены буквально, как в приложенном `story_data.json`, чтобы позже использовать их в SC03. Снимки хранят каждый посещённый ID и полное состояние переменных. Сохранения предыдущей истории совместимы.

## Изменённые файлы

Новый контент:

- `public/stories/neoreul_mideo/story.json` — метаданные, начальные флаги, корейский режим ученика.
- `characters.json` — Юна, Минсу, Сора.
- `nodes.json` — исходные реплики, выборы и переходы, учительские материалы.
- `scenes.json` — 25 кадров с исходными путями, заголовками сцен и безопасным расположением панели.
- `images/scene_01/*.jpg`, `images/scene_02/*.jpg` — исходные временные кадры.
- `public/stories/catalog.json` — новая карточка в общей библиотеке.
- `docs/trust-source/` — исходный сценарный JSON, manifest и документы из пакета для сверки.

Небольшие совместимые дополнения проигрывателя:

- `src/types.ts`, `src/values.ts`, `src/engine.ts` — строковые/неустановленные флаги, отдельная нода реакции, корректный возврат и проверка сохранений.
- `src/main.tsx` — корейские варианты в режиме ученика, материалы преподавателя, заголовки сцен, продолжение вместо финала, прямое открытие по параметру URL.
- `src/style.css` — только оформление учительских примечаний в существующей панели и читаемость корейского текста вариантов. Дизайн приложения не заменён.
- `src/validate.ts`, `public/stories/story.schema.json` — проверка новых необязательных полей.
- `src/trust.test.ts`, `package.json` — проверка всех маршрутов новой истории вместе с прежними тестами.

## Временные изображения

У каждого кадра в `scenes.json` есть `temporary: true`, `fit: "contain"`, исходный путь и метаданные безопасной области. В режиме преподавателя видна отметка TEMP с путём файла. Кадры вписываются без искажения и дополнительного кадрирования. Вшитые в исходные JPG поля и артефакты черновой раскадровки сохранены.

Для замены графики положите чистые изображения по тем же путям; текст и маршруты менять не нужно. Если в новых кадрах изменится композиция, обновите `faces` и `focus` в `scenes.json`. Для этих черновых кадров консервативно защищена вся центральная полоса с лицами, поэтому панель размещается снизу. На телефоне она, как и раньше, располагается под иллюстрацией.

## Проверить вручную

1. Начните заново. В SC01 выберите первый вариант `거기에서 뭐 했어요?`. Дождитесь реакции Минсу, продолжите до магазина. В конце выберите `민수하고 다시 이야기할 거예요.` → «Продолжение следует», SC03A.
2. Начните заново. В SC01 выберите второй вариант `거기에서 왜 시끄러웠어요?`. В магазине выберите `먼저 관리인에게 물어볼 거예요.` → «Продолжение следует», SC03B.
3. В SC01 выберите третий вариант. На реакции нажмите «Назад» и выберите первый или второй. Изменятся реакция и `first_question`; предыдущий выбор исчезнет из журнала.
4. Во второй сцене обновите страницу. Откроются тот же экран и кадр; `first_question` останется прежним. После последнего выбора обновление сохраняет также `route`.
5. Включите режим преподавателя на `SC01_12B` и `SC02_17`: видны исходные языковые примечания. На выборе видны русские задания и примеры; при выключении — только корейские варианты.
6. Проверьте ⛶, «Назад», перезапуск и предыдущую историю из библиотеки.

Автоматические проверки:

```sh
npm test
npm run validate
npm run build
```

12 тестов покрывают прежний движок и новую историю: шесть комбинаций маршрутов, реакции, возврат и изменение выбора, смену сцен, сериализацию строковых флагов и сохранение исходного текста/медиа.
