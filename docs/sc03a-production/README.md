# Seoul Stories — Scene 3A / «Полка»

**Статус:** production pack для Codex; **готовых игровых изображений нет**.

Содержит:
- `SC03A_FULL_SHOT_CARDS.md` — 6 режиссёрских карточек с composition/continuity/must-show/must-not/планом генерации и диалогами;
- `SC03A_DIALOGUE_READING.md` — все корейские реплики в двух версиях с переводом;
- `data/SC03A_content.json` — структурированные узлы, shot IDs, выбор, реакции, граф и флаги;
- `CODEX_TASK.md` — краткое задание на интеграцию;
- `references/` — итоговые кадры первой сцены и финальный скриншот второй, конвертированные в JPG **только как визуальные референсы** (не игровые кадры), плюс портреты;
- `assets/scene_03a/` — пустой каталог для новых полноформатных изображений.

## Сценарная последовательность
SH01 (D01, порог) → SH02 (D02–D05, вопрос) → SH03 (D06–D09, полка) → SH04 (D10–D11, шутка) → SH05 (D12, фотографии) → SH06 (D13–D15, доверие и выбор) → SH06 (реакция A или B) → следующая сцена/временная заглушка.

Ветка доступна только после `route=talk` из SC02, событие с шумом — **четверг**, пятничная ложь = `어제` в субботней сцене. Состояния охранника, измены и Соры не раскрываются.

**Запрещено использовать старую раскадровку с огромным повреждением стены — она визуально ошибочна.** Полка должна быть установлена и лишь немного криво висеть.
