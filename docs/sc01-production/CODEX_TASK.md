# Codex — внедрение SC01 в текущий Seoul Stories

## Контекст
Это **production packet**, НЕ самодостаточная игра и НЕ готовый storyboard-crop pack. Используй текущие репозиторий/движок/стиль *Seoul Stories*. Файл `data/SC01_content.json` — **нормализованный исходный контент**, не гарантированная схема текущего плеера: создай адаптер или импортируй в существующий формат после инспекции кода.

## Какие файлы чем являются
- `SC01_FULL_SHOT_CARDS.md`: главный human-readable источник правды. В нём все 8 карточек и корейские варианты каждой реплики.
- `data/SC01_content.json`: то же в структурированном виде; используй для валидации и интеграции.
- `references/approved_SC01_storyboard.png`: **только референс**, не использовать как изображение в игре.
- `references/Yuna_*`, `references/Minsu_*`: cropped refs лиц **только для генерации** (НЕ игровые активы).
- `assets/scene_01/`: место будущих восьми полноразмерных кадров, **сейчас пусто**.

## Порядок работы
1. Изучи текущую реализацию StoryPlayer, story data/branch navigation, teacher mode и режим Cinematic A. **Не делай новый проект с нуля**.
2. Валидируй граф nodes / choices / branch join и свойства continuity.
3. Генерируй/получи **восемь самостоятельных изображений**. Для каждого строго следуй shot card; используй визуальные reference, чтобы удержать лица, но **не копируй случайные ошибки раскадровки и не вырезай её панели**. Если генерация изображений из Codex не подключена, НЕ заменяй их растянутыми crop — сообщи о недостающей возможности и оставь заглушки, пока реальные изображения не будут предоставлены.
4. Все изображения с сохранением пропорций, ориентир **16:9, от 1920×1080**, без букв, подписей или UI внутри самой картинки. Если высокое разрешение недоступно, не растягивай исходники и не заявляй их высококачественными.
5. Привяжи последовательные node ID к одному shot ID (без анимационного переключения иллюстрации на каждой реплике). При переходе на новый shot старый shot не возвращается. Один веточный ответ остается на SH07.
6. Для каждого dialogue node реализуй `original`/`simple`. Кнопка **«Проще»** меняет только видимую корейскую строку, не сбрасывает прогресс, не меняет кадр и выбор. Следующий node по умолчанию снова original; teacher mode может видеть обе версии и RU.
7. На экране выбора основные кнопки **на русском** как действия (устный KR произносит студент). Примеры KR можно показать учителю по клику; не раскрывать их автоматически ученику. Реакция Минсу появляется после выбора на SH07, затем возврат к общему пути.
8. После SC01_D19 веди на существующий SC02_START. **Проверь содержание SC02:** там нужно говорить об инциденте в четверг, а не «вчера» в субботу.
9. На desktop не должно быть вертикального скролла. Весь выбор — поверх игрового кадра, минимальный chrome, доступные «назад», «дальше», teacher mode, fullscreen, autosave.

## Не делать
- Не заменяй идею шутки на прежнюю шутку о туалете.
- Не добавляй в SC01 телефон, неизвестную женщину или признаки измены.
- Не делай новое изображение ради каждого говорящего.
- Не добавляй незапланированные альтернативные реплики, новые сюжетные факты или неожиданные подозрительные выражения.
- Не дублируй кадр SH04 через другие кадры только ради ритма.

## Проверка завершения
- 8 уникальных shot IDs (не обязательно 8 готовых assets до завершения арт-процесса).
- Все 19 общих dialogue nodes + 3 branch response nodes (одна реакция на прохождение), 1 выбор/3 варианта; точные значения см. JSON.
- Переходы 3 вариантов сходятся в SC01_D17; затем SC01_D18, SC01_D19 и сцена 2.
- Пауза на выбор — без скролла и без подсказки готового корейского ученику.
- Кнопка упрощения меняет только реплику; безопасно работает на narratorial steps и веточных ответах.
- Персонажи узнаваемы на всех кадрах; реквизит, комната и фото из первого свидания согласованы.
