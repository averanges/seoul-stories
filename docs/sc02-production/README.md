# Seoul Stories — SC02 production packet v1

**Сцена:** «Покупки с Сорой» / 소라와 쇼핑. **Суббота днём.**

**Это НЕ готовая игра.** Пакет предназначен для Codex, который должен обновить SC02 в существующем проигрывателе, сгенерировать 8 новых иллюстраций и подключить содержимое. В пакете **нет** готовых финальных SC02 игровых изображений.

## Файлы
- `SC02_FULL_SHOT_CARDS.md` — 8 подробных карточек постановки, каждое изображение = 1 shot, full original/simple/KR/RU и учительские пометки.
- `SC02_DIALOGUE_READING.md` — все реплики подряд без режиссёрских деталей.
- `data/SC02_content.json` — структурированный контент, граф, выбор, флаги и черновая карта миграции старых SC02 ID.
- `CODEX_TASK.md` — короткое ТЗ для обновления сцены в существующей игре.
- `references/` — одобренный storyboard SC02 **только для режиссуры**, портреты Соры и Юны, дополнительный финальный кадр Юны из SC01.
- `assets/scene_02/` — запланированные будущие иллюстрации, сейчас пусто.

## Важные решения
- Восемь смысловых иллюстраций, не 26 иллюстраций на 26 реплик.
- Сора **физически добавляет третью розовую кружку** к двум уже выбранным Юной.
- Сора не «подсвечена» как подозрительная; её совет допускает обе интерпретации будущих концовок.
- Выбор: `route=talk` → разговор с Минсу (3A) или `route=investigate` → охранник (3Б). До появления этих сцен сохранить действующие заглушки.
- Календарь: четверг — визит и шум, пятница — звонок охранника и разговор с Минсу, суббота — покупки с Сорой.
- Совместимость: `first_question` из SC01 не трогать; existing SC02 сохранения переносить по смыслу.
