# SC02 — «Покупки с Сорой» / 소라와 쇼핑

**Статус:** production pack для Codex. Финальные игровые изображения **ещё не созданы**. Утверждать только после просмотра сцены.

**Продолжение SC01:** суббота днём; это не пересказ той же сцены в магазине, а отдельная мини-история с двумя шутками и эмоциональным поворотом.

**Монтаж:** одна SH-карточка = один уникальный кадр; он держит один или несколько последовательных dialogue nodes. После перехода к следующему кадру не возвращаться к предыдущему. Russian choice labels, teacher-only Korean answer examples. Смена original/simple не меняет картинку.

## Критические сюжетные и календарные правила
- SC01 случилась в пятницу вечером. Минсу был в новой квартире в четверг; в пятницу он сначала это отрицал, затем признал визит.
- SC02 случается в субботу днём. В субботу «어제» означает пятницу, только для разговора/звонка охранника. Визит и шум: 목요일, не 어제.
- SC01 first_question остаётся неизменным; SC02 задаёт только route=talk/investigate.
- Сора выглядит и говорит как дружелюбная подруга. В версии A невиновна, в версии B поддерживает, в версии C может иметь скрытый мотив; в SC02 не выдаёт свою роль.
- Сора до следующей сцены не знает/не обсуждает, что охранник видел поцелуй или другую женщину; эти факты ещё не раскрыты.
- Две кружки Юны — кремовая и голубая. Третья, розовая, добавлена Сорой на SC02_SH04; дальнейшие кадры не должны возвращать две кружки.
- Юна между сценами меняет одежду и причёску, но сохраняет черты лица из финальных SC01 кадров. Сора использует вторую утверждённую раскадровку и Sora face refs.

### SC02_SH01 — Суббота: магазин для дома · required

- **Драматургический блок:** Установление места
- **Зачем кадр:** Сразу показать, что действие переместилось из домашнего вечера в яркий магазин за вещами для совместной квартиры.

- **Реквизит:** Диваны, лампы, витрины посуды и небольшие ценники НЕ читаемым текстом.
- **Continuity:** Начало дня; покупок и корзины ещё нет.
- **Безопасная зона текста:** Нижние 25% без важных лиц; чистая зона под диалог.

## Часть B. Итоговый выбор

**SC02_CHOICE_ROUTE** (на `SC02_D26`): К кому Юна обратится сначала?

- **talk: Сначала поговорить с Минсу**
  - Устное задание: Скажи по-корейски: «Сначала ещё раз поговорю с Минсу».
  - Original для учителя: `민수한테 다시 직접 물어볼게요.`
  - Simple для учителя: `민수하고 다시 이야기할 거예요.`
  - Реакция: `SC02_R_TALK` → символическая цель `SC03A_START`
  - Флаг: `route=talk`
- **investigate: Сначала поговорить с охранником**
  - Устное задание: Скажи по-корейски: «Сначала спрошу охранника».
  - Original для учителя: `경비 아저씨한테 먼저 목요일 일을 물어볼게요.`
  - Simple для учителя: `먼저 경비 아저씨에게 물어볼 거예요.`
  - Реакция: `SC02_R_CHECK` → символическая цель `SC03B_START`
  - Флаг: `route=investigate`

**Важно:** после выбора реакция Юны остаётся на SH08. Никакого нового изображения ради её произнесённой вслух реплики. Символические цели не считаются существующими ID движка; до реализации SC03 оставить нынешние route-end screens.

## Часть C. Словарь и педагогика

- **Original** — преимущественно 1B–2A, но в реплике SC02_D16 более сложная косвенная речь осознанно оставлена для естественности.
- **Simple** — короче, преимущественно 1A–1B; цель 0–1 новая единица на реплику, допускаются 2 при визуальной поддержке.
- Ключевые повторения: `컵`, `세 명`, `새집`, `목요일`, `경비 아저씨`, `거짓말`, `이사 준비`.
- В обеих версиях общие факты обязаны совпадать. Упрощение НЕ добавляет женщину, поцелуй или личность Соры.
- Оба персонажа используют 해요체 как учебную конвенцию текущей новеллы. В реальной дружеской беседе 반말 тоже был бы естественен.
- Перевод, грамматика, лексика, образцы ответа — только teacher mode.

## Часть D. Рискованные места на проверку при монтаже

1. **SH02 (6 реплик):** диван действительно должен визуально позволять сесть втроём; иначе шутка ломается.
2. **SH04:** без настоящего действия добавления третьей розовой кружки пропадает двойной смысл.
3. **SH05:** не преувеличивать тревогу; Юна только на секунду отвлеклась.
4. **SH06 (7 реплик):** это самый длинный удерживаемый кадр; проверить чтение в плеере. Добавлять резервный кадр только если удержание реально не работает.
5. **SH07:** если Сора выглядит зловещей, отклонить изображение; зрителю сейчас не нужно предсказывать концовку C.
6. **SH08:** решение принадлежит Юне, а не Соре; не показывать указующие на «правильный выбор» жесты.
