# SC04B — Ночной звонок: готовая интеграция

Новая сцена SC04B_PHONE включена в общую игровую сборку истории neoreul_mideo. Источник текста — неизменённый docs/sc04b-nightcall-production/data/SC04B_content.json. Общий дизайн и код плеера/движка не менялись.

## Вход и выходы

Маршрут: SC02 → SC03A (полка) → выбор проверки → SC03B (охранник) → SC03B_TO_SC04B → SC04B_PHONE_D01. Вход D01 требует guard_reports_kiss=true и shelf_seen=true; при отсутствии одного из условий технический переход возвращает к SC02_D26. Прямой путь без полки остаётся SC03B_TO_SC04A → SC04A_CONFESSION_D01. Доверие остаётся SC03A_R_TRUST → дневной мостик → SC04A_D01 → ENDING_A_FALSE_PEACE.

Двенадцать общих узлов SC04B_PHONE_D01–D12, затем одна из реакций SC04B_PHONE_REACT_KNOW / SC04B_PHONE_REACT_LEAVE. Символический CHOICE сопоставлен с D12: без лишнего повторного вопроса и пустого экрана.

Выходы:
- KNOW → SC04B_PHONE_TO_IDENTITY — рабочая заглушка будущего поиска личности.
- LEAVE → SC04B_PHONE_TO_ENDING_B — рабочая заглушка будущего финала B.

Следующие эпизоды пока не написаны; обе заглушки показывают «Продолжение следует», сохраняют SH03 и имеют реальные существующие ID. Символические SC05_IDENTITY_START и ENDING_B_START не оставлены битыми ссылками. Сцены SC04A и SC04B используют собственные заглушки, чтобы не менять последнюю иллюстрацию на чужой маршрут.

## Текст, преподаватель и флаги

Original/Simple/RU и teacher notes перенесены дословно. Грамматика и лексика разбиты по точкам с запятой в существующие массивы teacher.grammar/vocab. На D04, D11 и D12 «Проще» скрыта; на остальных узлах и обеих реакциях работает с обычным сбросом при переходе. Выбор — по-русски, корейские образцы выбора доступны только в панели преподавателя. После выбора выводится отдельная утверждённая реакция, а не подмена её образцом ответа.

Новый текстовый speaker minsu_phone отображается как «민수 · 전화», без графического портрета. Как и остальная игра, звонок передаётся письменными репликами; аудио не создавалось.

При D01 устанавливается только новый sc04b_call_visited=true. При D06 — существующий minsu_confessed=true. Обе развилки используют существующие identity_investigation_chosen/yuna_declines_identity. Факты охранника и посещение полки не обнуляются; имя женщины не раскрывается. sora_identity_known/sora_involved и флаги счастливого финала не устанавливаются. Для старых сохранений добавлен только false-default sc04b_call_visited. Сохранения прежней заглушки SC03B_TO_SC04B теперь продолжают звонок, остальные ID не переименованы.

## Проверки

46 тестов проходят, валидация всех трёх историй без ошибок, production-сборка успешна. Отдельная проверка SHA-256 подтверждает неизменность всех прежних игровых изображений, кода движка и UI; прежние узлы изменены только в подключении SC03B_TO_SC04B.

Браузер: полный вход от выбора SC03A через все 16 реплик SC03B к звонку; 12 общих реплик, три изображения, teacher RU/образцы, сброс «Проще», D06-признание, две разные реакции и заглушки, замена выбора через «Назад», reload, restart, fullscreen. Дополнительно проверены прямой путь в SC04A_CONFESSION и доверие к дневному мостику. Экраны 1440×900, 1280×720 и 390×844 без переполнения документа/реплик. Скриншоты outputs/sc04b-phone-*.png.
