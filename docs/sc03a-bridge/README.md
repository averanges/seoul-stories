# Мостик SC03A → финал A

Единственный новый узел SC03A_BRIDGE_D01 и новая игровая иллюстрация SC03A_BRIDGE_SH01.png. Вход только из SC03A_R_TRUST, выход в существующий SC04A_D01. Предыдущие тексты и иллюстрации не изменены. Ветка охранника сохранена.

Кадр сгенерирован встроенным image_gen по референсам лиц SC01 и квартиры SC03A, проверен визуально: Юна на коленях слева разбирает книги, Минсу справа складывает упаковку, окно слева, пустая полка на двух металлических кронштейнах справа, дневной свет. Небольшие различия перспективы/длины полки допустимы для нового ракурса; точное геометрическое или биометрическое тождество генерации не заявляется. Исходник 1672×941, без обрезки и увеличения. Промпт и роли референсов — GENERATION_PROMPT.md.

Дневной текст ждёт нажатия «Дальше». Затем transitionAfter показывает корейский титр на отдельном тёмном overlay 1800 мс, без новой иллюстрации или сюжетного узла, после чего выполняется обычный advance. Начальное лёгкое появление титра — 180 мс; учитывается prefers-reduced-motion. Перевод титра и его обе корейские формы доступны преподавателю; «Проще» у титра имеет независимое состояние и начинается с оригинала. Открытая панель преподавателя/диалог приостанавливает титр для чтения.

Титр не добавляет записей в историю и не меняет переменные. «Назад» во время титра отменяет его и оставляет мостик, повторный «Назад» возвращает предыдущий узел. Перезагрузка во время титра восстанавливает сохранённый дневной узел, без автоматического пропуска текста. После входа в финал обычный возврат ведёт на мостик.

Проверки: 36 тестов, валидация трёх историй, production-сборка. Браузер: выбор доверия → реакция → новый кадр → обе версии реплики → учительские перевод/лексика/титр → затемнение → обе версии титра → отмена таймера → SC04A_D01 → возврат/перезагрузка; мобильный экран 390×844 без прокрутки документа и переполнения реплики. Скриншоты лежат в outputs/sc03a-bridge-*.png.

Демо: http://localhost:5180/?story=neoreul_mideo . Для просмотра в панели преподавателя перейти к SC03A_D15 и выбрать доверие либо сразу к SC03A_BRIDGE_D01.
