# Seoul Stories — SC04A Confession Production Pack

Файл `CODEX_TASK.md` — краткая инструкция Codex. `SC04A_FULL_SHOT_CARDS.md` — полноценная режиссура шести уникальных кадров со связанными репликами. `SC04A_DIALOGUE_READING.md` — чтение диалога подряд. `SC04A_VISUAL_BIBLE.md` — строгие визуальные правила. `data/SC04A_content.json` — структурированный переносимый контракт (это **не** готовая schema для плеера). `references/` — подлинные игровые изображения SC01, сжатые до компактных JPEG, а не новые рисунки. `assets/scene_04a_confession/` — место под изображения, которые Codex должен создать.

**Сцена:** 4A — первая личная конфронтация в СТАРОЙ квартире после прямого разговора с охранником; без сцен 3A «Полка». Есть другая сцена 4B (звонок), и отдельный счастливый финал A. НЕ путать эти сцены.

**Статус:** утверждённый базовый сюжет, реплики подготовлены на корейском с упрощениями. Арты ещё не сгенерированы. Нельзя ссылаться на эти референсы как на готовые новые изображения сцены.

**Языковые правки относительно раннего черновика:** заменено неестественное `당신` в обращении пары; `simple` действительно упрощает косвенную речь; реплика о поцелуе указывает свидетельство охранника и не раскрывает женщину. Остальные события не изменены.
