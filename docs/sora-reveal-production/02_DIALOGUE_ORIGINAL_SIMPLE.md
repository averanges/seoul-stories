## Преподавательские комментарии

- **R01:** повторение `-는지 알다/모르다` через `누군지 알고 싶어요` — косвенный вопрос; simpler version убирает форму, не меняя решение игрока.
- **R02:** `제발` — «пожалуйста, умоляю», по контексту просьба не продолжать.
- **R03:** `숨기다` — скрывать; `-지 말고` — не делай X, а сделай Y; `말해 줘요` — скажи (мне). Simple оставляет повелительную просьбу.
- **R04:** `소라` — имя персонажа. **Оба уровня одинаковые, кнопку «Проще» скрыть.**
- **R05:** `제 친구` — моя подруга; простая версия оставляет суть: Юна уточняет, речь именно о её подруге.
- **R06:** `정말` — действительно/очень, убрано при упрощении.
- **R07:** `더는` — больше (не...), `-고 싶지 않다` — не хотеть; simple использует `듣기 싫다` как более доступную формулировку, при необходимости объяснить `-기`.
- **OUT-A:** `남다` — оставаться; simple заменяет на `혼자 있어요`.
- **OUT-B:** `전화를 끊다` — завершить телефонный разговор. Ключевое выражение; объяснить на месте.

**Педагогическое правило:** после каждого шага показывать `original`; по кнопке «Проще» заменять лишь текущую фразу, после перехода сброс. Ни одна версия не называет Сору раньше R04.
