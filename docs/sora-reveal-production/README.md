# Seoul Stories — Sora Name Reveal Add-on for 4A + 4B

**Задача:** добавить короткое раскрытие имени Соры **после существующего выбора KNOW** к двум версиям сцены признания. Не пересобирать уже готовые сцены и не генерировать изображения от имени ChatGPT.

Состав:

- `01_SCRIPT_LOCK.md` — короткий сценарий и сохранённая логика веток.
- `02_DIALOGUE_ORIGINAL_SIMPLE.md` — общий корейский диалог, упрощение, перевод, преподавательские заметки.
- `03_EXTRA_SHOT_CARDS.md` — 2 новых кадра к 4A и 1 к 4B, ракурсы, эмоции, запреты.
- `04_CODEX_TASK.md` — точные ограничения patch/integration и приёмочные тесты.
- `data/reveal_addon.json` — структурированный контент-контракт (не прямой импорт игрового движка).
- `references/` — резервные уже утверждённые визуальные референсы. Codex должен предпочесть **текущие** игровые изображения из локального проекта.

**Не генерировать изображение Соры при раскрытии имени.** Следующий сюжетный блок — отдельная конфронтация Юны и Соры, `SC06_SORA_CONFRONT_START` (пока символический переход).
