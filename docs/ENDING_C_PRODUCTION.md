# Ending C — Никого / 혼자

Встроено в существующую story `neoreul_mideo`. Движок и интерфейс не изменены.

## Фактический маршрут

`SC06_D34 → ENDING_C_D01 → … → ENDING_C_D06 → ENDING_C_TERMINAL`.

Три изображения: SH01 для D01–D02, SH02 для D03–D05, SH03 для D06 и экрана конца. Все шесть строк рассказчика, original/simple, перевод, грамматика и лексика перенесены из исходного контракта. Новых выборов нет.

Прежний служебный узел `ENDING_C_START` удалён, но его ID сохранён в таблице миграции; сохранения на бывшей заглушке переводятся на `ENDING_C_D01`. Первый узел проверяет `sora_identity_known`. Требование завершённой конфронтации обеспечено маршрутом: единственный сюжетный вход — из последнего шага SC06; отдельный дублирующий флаг `sora_confrontation_complete` не добавлен. Прямой переход учителя остаётся отладочной возможностью существующего плеера.

Заключительная строка удерживается до нажатия «Дальше», затем открывается штатный экран `혼자` / `끝 C — 혼자` (в режиме преподавателя «Конец C — Никого»). Автоматический таймер не добавлен согласно visual bible. «Назад» возвращает к D06 на том же кадре.

## Изображения

Три новых самостоятельных кадра встроенным image_gen, каждый 1672 × 941, приблизительно 16:9. Исходники PNG: `outputs/ending-c-originals/ENDING_C_SH01.png`–`ENDING_C_SH03.png`. Игровые WebP: `public/stories/neoreul_mideo/assets/ending_c/`. Без обрезки или увеличения, WebP quality 95.

SH01: закрытая дверь старой квартиры, Юна с сумкой после кафе. SH02: крупный план закрытого альбома, одного телефона и руки. SH03: обратный ракурс от окна, диван справа, столик слева, Юна одна, заметное свободное место. Нет новых окон/дверей, полки, Соры, Минсу, пива, еды и читаемого экрана. Во всех кадрах мягкое ночное домашнее освещение. Лицо, открытый кремовый кардиган, белая футболка, джинсы и причёска сверены с текущей SC06. Субъективное сходство лица и монтажный ритм доступны для дальнейшей авторской оценки.

Промпты: `ending-c-production/GENERATION_PROMPTS.json`; размеры и контрольные суммы: `ending-c-production/ART_MANIFEST.json`. Исходный пакет сохранён в `ending-c-production` без переписывания сценария.

## Проверка

Новый тест сопоставляет все шесть строк и материалы учителя с пакетом, проверяет три уникальных файла, последовательность кадров, окончание, возврат, сохранение и миграцию заглушки. Снимок до интеграции проверяет неизменность старых изображений, финалов A/B, остальных текстов и файлов плеера. Разрешённые изменения старых узлов: только переход `SC06_D34` и прежняя заглушка `ENDING_C_START`.

Браузерная проверка: original/simple каждого шага, перевод/грамматика/лексика, возврат и перезагрузка, завершённый экран C, настольный 1280×720 и мобильный 390×844, обе ветки отказа по-прежнему ведут в B. Локальная игра: http://localhost:5180/?story=neoreul_mideo.
